--------
Delete Conditions:
First-time Delete:
rag_status = not_indexed or failed

Retry Delete:
rag_status = deactivated
AND has Delete job in pending/processing/failed state

Indexed/published version:
Must Deindex first
---------
Final Result:
PostgreSQL:
- Document version deleted
- Chunks, jobs, recipients, and asset links deleted
- Document deleted only if no other versions remain

R2:
- Canonical Markdown deleted
- Source file deleted

Qdrant:
- Remaining vectors of version deleted

Chatbot:
- Cannot retrieve version

Recovery:
- Cannot recover after Delete completion
